# Pedro Simões — Video Editor

Portfólio estático desenvolvido em HTML, CSS e JavaScript, pronto para GitHub Pages.

## Estrutura

- `index.html`: conteúdo e estrutura semântica.
- `style.css`: identidade visual, responsividade e animações.
- `script.js`: menu mobile, animações de entrada e reprodução dos projetos.

Os vídeos são carregados sob demanda a partir do Google Drive para manter a página inicial leve.

O workflow em `.github/workflows/deploy-pages.yml` publica automaticamente as alterações da branch `main` no GitHub Pages.
